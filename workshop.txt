title=Carry Weight Multiplier
description=[h1]Carry Weight Multiplier[/h1]
description=Carry more without changing how heavy anything really is. This mod multiplies the weight items count for in carry and capacity checks, and leaves their real weight alone. By default everything counts for a tenth, so characters, bags, vehicles and the floor hold ten times as much.
description=
description=[h2]Sandbox option[/h2]
description=[b]Carried weight multiplier[/b], from 0 to 1. 0.1 (default) counts a tenth, 0 counts nothing, 1 is vanilla. Set it when you start a new game, or in the server's sandbox settings.
description=
description=[h2]What counts less[/h2]
description=[list]
description=[*]Items in your inventory, in bags, in hands, worn and on the hotbar, fluids included
description=[*]Containers, vehicle storage and the floor
description=[*]Furniture: the check before picking it up, the cursor panel and the item once it is in your inventory
description=[*]The check on the menus for taking down curtains and light bulbs
description=[/list]
description=
description=[h2]What stays vanilla[/h2]
description=Each item's real weight, weapon stamina, action times (furniture pickup included), fuel burn time, foraging and fish.
description=
description=[h2]Side effects[/h2]
description=[list]
description=[*]Strength rises less often from walking loaded, because that needs a load over half the carry limit.
description=[*]Vehicles gain less mass from cargo.
description=[*]Weight numbers in the UI show the counted weight, except for animals.
description=[*]Other mods that read these weights see the counted weight too. Build Ahead, for example, fetches more materials per trip.
description=[/list]
description=
description=[h2]Requirements[/h2]
description=[list]
description=[*][b]ZombieBuddy[/b] (Java mod loader), enabled in the mod list
description=[*]Steam launch option [b]-agentlib:zbNative --[/b] (Project Zomboid → Properties → Launch options). Without it the mod does not load.
description=[/list]
description=On the first start ZombieBuddy asks once to approve CarryWeightMultiplier.jar.
description=
description=[h2]Compatibility[/h2]
description=Build 42. Single player tested. Multiplayer is not tested: the server and every client would need ZombieBuddy and this mod. Works when added to an existing save, which then uses the default 0.1. The mod changes no item data, so weights count as vanilla again once it is removed; a load that only fit because of the mod may then leave you overloaded.
description=
description=[h2]한국어[/h2]
description=아이템의 실제 무게는 그대로 두고, 적재량과 용량 계산에 쓰는 무게에만 배율을 곱합니다. 기본값 0.1이면 캐릭터, 가방, 차량, 바닥에 10배까지 실을 수 있습니다. 가구 들기와 커튼, 전구 떼어내기 메뉴의 무게 검사도 같은 배율을 따릅니다.
description=샌드박스 옵션 [b]적재 무게 배율[/b](0~1): 0.1은 10분의 1, 0은 무게 없음, 1은 바닐라와 같습니다. 새 게임을 시작할 때나 서버 샌드박스 설정에서 정합니다.
description=무기 스태미나, 행동 시간, 땔감 시간, 채집, 생선은 바닐라 그대로입니다. 대신 짐을 지고 걸을 때 오르는 힘 경험치가 드물어지고, 차에 짐을 실어도 차가 덜 무거워집니다.
description=필요한 것: [b]ZombieBuddy[/b] 모드, 스팀 실행 옵션 [b]-agentlib:zbNative --[/b] (속성 → 실행 옵션). 싱글에서 테스트했고 멀티는 테스트하지 않았습니다. 멀티에서는 서버와 모든 클라이언트에 ZombieBuddy와 이 모드가 필요합니다.
